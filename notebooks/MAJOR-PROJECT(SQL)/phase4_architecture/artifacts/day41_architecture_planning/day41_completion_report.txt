TECHNICAL SPECIFICATIONS SUMMARY
================================================================================

BRANCH 1: CHARACTER-LEVEL DETECTION
  Purpose:      Fine-grained obfuscation and encoding detection
  Input Shape:  [batch_size, 1024]
  Input Source: train_char_tokenized.parquet
  Layers:       11 (Embedding -> Conv1D x3 -> GlobalMaxPool -> Dense x2)
  Output:       [batch_size, 128]
  Regularization: Dropout 0.5, L2 0.01, BatchNorm
  Justification: Highest dropout (0.5) to prevent overfitting on character patterns

BRANCH 2: WORD-LEVEL SEMANTIC
  Purpose:      Contextual understanding through token sequences
  Input Shape:  [batch_size, 150]
  Input Source: train_word_tokenized_raw.parquet + token_types
  Layers:       11 (Embed + TokenTypeEmbed -> Conv1D x2 -> GlobalAvgPool -> Dense x2)
  Output:       [batch_size, 128]
  Regularization: Dropout 0.3, L2 0.01, BatchNorm
  Justification: Moderate dropout for semantic complexity

BRANCH 3: STRUCTURAL FEATURES
  Purpose:      High-level syntax and semantic feature extraction
  Input Shape:  [batch_size, 104]
  Input Source: Statistical (34) + Syntax (34) + Semantic Roles (36)
  Layers:       8 (LayerNorm -> Dense x3 with BatchNorm)
  Output:       [batch_size, 128]
  Regularization: Dropout 0.3, L2 0.01, BatchNorm
  Justification: Engineered features require moderate regularization

FUSION MODULE: MULTI-BRANCH ATTENTION
  Strategy:     Concatenation + Multi-Head Attention
  Input:        [384] (concatenated branch outputs)
  Attention:    3 heads, key dimension 64
  Output:       [256] (fused feature vector)
  Purpose:      Dynamically weight branch contributions per sample
  Regularization: Dropout 0.3, L2 0.01

UNCERTAINTY MODULE: MULTI-HEAD CLASSIFICATION
  Strategy:     3 parallel classifiers + temperature scaling
  Heads:        3 independent Dense(128) -> Dense(2) classifiers
  Purpose:      Ensemble voting for uncertainty quantification
  Outputs:
    1. Classification: [2] softmax probabilities
    2. Confidence: [1] temperature-scaled confidence
    3. Variance: [1] epistemic uncertainty
    4. Epistemic: [1] head disagreement measure
  Regularization: Dropout 0.2 per head, L2 0.01
